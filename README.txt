КИНОТРЕКЕР — установка на iPhone

1. Распакуйте архив.
2. Загрузите ВСЕ файлы из папки в корень публичного GitHub-репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), нажмите Save.
5. Дождитесь адреса сайта. Откройте его в Safari на iPhone.
6. Нажмите Поделиться → На экран «Домой».

Каталог TMDB:
Создайте аккаунт на themoviedb.org, получите API Read Access Token в настройках API и вставьте его в ⚙️ приложения.
Фильмы, заметки, оценки и избранное хранятся локально в браузере. Используйте экспорт для резервной копии.
Для публичного коммерческого приложения хранение API-токена на клиенте не рекомендуется — нужен серверный прокси.
